### 🚀 About Me

I'm an independent full-stack developer from India, building web applications end-to-end — from database design to pixel-perfect UI. I care about products that solve real problems, especially for communities that are often overlooked by mainstream tech.

- 🔭 Currently building **TradeConnect India** — a professional networking & hiring platform for India's industrial and blue-collar workforce
- 📚 Also running **Python Hindii** — a Hindi-language platform teaching Python, MySQL & AI to Hindi-medium learners
- 🛠️ I work across the stack: React/Next.js on the front, Node/Express on the back, and whatever database the job calls for
- 🌱 Always learning, always shipping
- 💬 Ask me about React, Next.js, Supabase, or building for non-English-first audiences
