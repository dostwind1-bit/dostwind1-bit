I'm an independent **full-stack developer** from India, building web applications end-to-end — from database design to pixel-perfect UI. I care about products that solve real problems, especially for communities that mainstream tech often overlooks.

- 🔭 **Currently building:** [TradeConnect India](https://github.com/dostwind1-bit/tradeconnectindia) — a LinkedIn/Naukri-style networking & hiring platform for India's industrial and blue-collar workforce
- 📚 **Also running:** Python Hindii — a Hindi-language platform teaching Python, MySQL & AI to Hindi-medium learners
- 🛠️ **Full-stack range:** React/Next.js on the front, Node/Express on the back, and whichever database the job calls for
- 🌱 **Always shipping:** new features, new products, new problems to solve
- 💬 **Ask me about:** React, Next.js, Supabase, or building products for non-English-first audiences
- ⚡ **Fun fact:** I deploy on Blogger *and* Vercel — whatever gets the job done fastest
